1. `flutter test` падает сразу с «Flutter failed to delete file …build\native_assets\windows\sqlite3.dll»,
   если параллельно идёт другой `flutter_tester.exe` (другой агент или терминал пользователя).
   Процессы не убивать — повторять прогон с паузой (скрипт-цикл в scratchpad, запуск в фоне).
   **Why:** M4.13 — два агента работали в одной папке одновременно.
   **How to apply:** при этой ошибке — повтор, а не поиск причины в коде.

2. Два `TestDevice.start(seed: N)` с одним seed дают РАЗНЫЕ id: время в UUIDv7 берётся из
   `package:clock`, а не из `FixedClock` устройства. Для сравнения баз двух устройств по таблицам
   (эквивалентность «массово» против «по одной») — тело теста и старт устройств внутри
   `withClock(Clock.fixed(testStart), ...)`.
   **Why:** первый вариант теста эквивалентности упал на разных id проекта.
   **How to apply:** любой тест, где два устройства должны получить одинаковые id без синхронизации.

3. Мутационная проверка нужна для оптимизаций снимка: первый тест эквивалентности пропускал все
   мутации `_Steps` — данные не задевали случаи (равные ключи у соседей с нужным порядком id, две
   удалённые метки с одним именем, пришедшая задача в архивном разделе у предела 300).
   См. [[bulk-steps-snapshot]].
