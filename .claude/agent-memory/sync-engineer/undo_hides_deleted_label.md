Workspace показывает удалённую метку на выполненной задаче, только если HLC `is_completed` задачи
раньше HLC удаления метки. Любое «Отменить», которое возвращает задаче `is_completed=true`
(например, после сброса подзадач повторяющейся задачи, О-70), пишет новую op — её HLC позже
удаления, и метка на задаче больше не видна, хотя связь `task_label` восстановлена.
**Why:** найдено в M4.13 при исправлении О-70; правило — SYNC_DESIGN «Специальные случаи», менять
его — Decision Gate.
**How to apply:** при правке Undo или правила видимости удалённых меток — помнить; тест О-70
проверяет связь в `field_versions`, а не `ws.task().labelIds`.
