Разобрано 2026-11-14 (WebFetch — пересказ). customize-views-in-todoist-AoHhBxFdZ (en+ru): Display -> Filter доступен у "project, label, filter, Inbox, or Today view"
(Upcoming не назван); категории Assignee / Date / Deadline / Priority / Label / Workspace; ru: «Срок» («Задачи в пределах временного промежутка»), «Дедлайн»,
«Приоритет», «Метка». Конкретных значений (today/this week/...), мультивыбора, смысла Reset all — НЕТ (WebSearch тоже: значения нигде не найдены).
Reset all только гасит оранжевую точку. sort-or-group: фильтра в Display не описывает; "can't be manually reordered" у filter/label views.
ru introduction-to-filters: страница списка — «Фильтры и метки»; «Мои фильтры» на странице НЕ встречается; поля: название («Назовите фильтр» моб.), «Запрос»,
«Цвет», «Описание» (в диалоге + «Добавить описание» под названием), «Избранное»; меню «Изменить фильтр», «Удалить фильтр»; «Дублировать» нет.
Расхождение найдено: наш подпункт фильтра даты называется «Дата» (viewFilterDate), help ru и группировка в нашем же меню — «Срок» (viewByDate/fieldDue).
