# Синтаксис Todoist (для парсеров)

Справочник собран по документации Todoist 2025–2026. Перед реализацией каждого раздела
parity-reviewer сверяет его с актуальной страницей help (Quick Add, Recurring due dates,
Introduction to filters, Deadlines) и дописывает недостающие формы в test/fixtures.

## 1. Quick Add — токены

| Токен | Пример | Смысл |
|---|---|---|
| `#Проект` | `#Работа`, `#"Дом и быт"` | проект; автодополнение по вводу, имя с пробелами — через выбор из списка или кавычки |
| `/Раздел` | `/Встречи` | раздел внутри проекта |
| `@метка` | `@ждёт @дом` | метка, несколько подряд |
| `p1`…`p4` | `p1` | приоритет; p4 = без приоритета (по умолчанию) |
| `!` + дата/время | `!завтра 9:00`, `!за 30 мин` | напоминание (абсолютное или относительно срока) |
| `{дата}` | `{15 янв}`, `{Jan 15}` | дедлайн (отдельное поле, без времени) |
| `на N мин/ч` / `for N min/h` | `на 30 мин`, `for 2h` | длительность; только вместе со сроком со временем |
| `//` | `Купить молоко //2 литра` | всё после — описание |
| дата/время в тексте | `завтра в 17:00`, `next monday 5pm` | срок; распознаётся автоматически и подсвечивается; клик по подсветке отменяет разбор |
| несколько строк | вставка текста с переносами | предложить создать несколько задач |

Распознанные токены удаляются из названия. Приоритет разбора: явные токены → повторение → дата → время → длительность.

## 2. Даты (ru / en)

Относительные: `сегодня/today`, `завтра/tomorrow/tom`, `послезавтра`, `вчера/yesterday`,
`через N дней/недель/месяцев` / `in N days`, `N days` (= через N дней), `следующая неделя/next week`
(= следующий понедельник), `следующий месяц/next month` (= 1-е число), `конец месяца/end of month`,
`выходные/this weekend`.
Дни недели: полные и короткие (`пн`, `вт`… / `mon`, `tue`…); без уточнения — ближайший будущий;
`следующий пн/next monday` — через неделю от ближайшего, как в Todoist.
Абсолютные: `15 янв`, `15 января`, `15.01`, `15.01.2026`, `Jan 15`, `15 Jan`, `2026-01-15`;
без года — ближайшая будущая дата.
Время: `в 17:00`, `17:00`, `в 5 вечера`, `5pm`, `5p`, `9am`, `утром` (9:00), `вечером` (19:00) — значения
по умолчанию берутся из настроек. Дата без времени — «весь день». Срок в прошлом — допустим (просрочено).

## 3. Повторения

| Форма (ru / en) | Семантика |
|---|---|
| `каждый день` / `every day`, `daily` | ежедневно |
| `каждую неделю` / `every week`, `weekly` | еженедельно в тот же день недели |
| `каждый месяц` / `every month`, `monthly` | в то же число; 31 → последний день короткого месяца |
| `каждый год` / `every year`, `yearly` | та же дата |
| `каждые 2 дня`, `каждые 3 недели` / `every 2 days`, `every other week` | интервалы |
| `каждый пн, ср, пт` / `every mon, wed, fri` | по дням недели |
| `каждый рабочий день` / `every weekday`, `every workday` | пн–пт |
| `каждые выходные` / `every weekend` | сб (и вс — уточнить по help) |
| `каждое 15 число` / `every 15th`, `every 1st` | по числу |
| `каждый последний день месяца` / `every last day` | последний день |
| `каждый 3-й пт` / `every 3rd friday`, `every last friday` | n-й день недели в месяце |
| `каждый год 1 мая` / `every jan 1` | ежегодно по дате |
| `каждое утро` / `every morning` (9:00), `every evening` (19:00) | ежедневно с временем |
| `каждый день в 10:00` / `every day at 10am` | повторение с временем |
| `каждый! 3 дня` / `every! 3 days` | **от даты завершения**, а не от срока |
| `… с 1 мая` / `… starting jan 1` | начало серии |
| `… до 30 июня` / `… ending jun 30`, `… until jun 30` | конец серии |
| `… 5 раз` / `… for 5 times` | ограничение по числу (уточнить по help) |

Сокращения en: `ev` = every. Правило хранится как RRULE-строка + флаг `from_completion`.

Семантика завершения: завершение переносит срок на следующее вхождение (от срока или от завершения
при `every!`); «Пропустить» — то же без записи выполнения; «Завершить навсегда» — закрывает серию;
изменение даты одного вхождения не меняет правило; подзадачи повторяющейся задачи при новом цикле
снова становятся незавершёнными. Все переходы — через ops.

## 4. Язык фильтров

Операторы: `&` и, `|` или, `!` не, `( )` группировка, `,` — несколько списков в одном фильтре
(каждый список — отдельная секция результата).

| Запрос | Смысл |
|---|---|
| `today`, `tomorrow`, `yesterday` | срок в этот день |
| `overdue`, `od` | просрочено |
| `no date`, `no due date` | без срока; `no time` — срок без времени |
| `7 days`, `next 7 days`, `next week`, `this week` | диапазоны |
| `date before: May 5`, `date after: today`, `due before: +4 hours`, `date: Jan 3` | сравнение; `due` и `date` эквивалентны; относительные `+N hours/days`, `-N days` |
| `deadline: today`, `deadline before:`, `deadline after:`, `no deadline` | по дедлайну |
| `created: today`, `created before: -30 days`, `created after:` | по дате создания |
| `recurring`, `!recurring` | повторяющиеся |
| `p1`, `p2`, `p3`, `p4`, `no priority` (= p4) | приоритет |
| `#Работа`, `#"Два слова"`, `##Работа` | проект; `##` — включая подпроекты |
| `/Встречи`, `no section` | раздел |
| `@дом`, `@дом*`, `no labels`, `@*`? | метки; `*` — подстановка (уточнить по help) |
| `search: отчёт` | текст в названии/описании |
| `subtask`, `!subtask` | подзадачи |
| `view all` | все активные задачи |
| `assigned to:`, `assigned by:`, `shared`, `workspace:` | **вне scope** — распознать и показать «не поддерживается» |

Ключевые слова — английские; русские эквиваленты (`сегодня`, `просрочено`, `без даты`, `без меток`)
поддержать как синонимы. Имена проектов/меток — без учёта регистра. Ошибка синтаксиса — подсветка
позиции и сообщение, как в Todoist; пустой результат — не ошибка.

Каждый пример из таблиц выше должен присутствовать; новые формы из help добавляются сюда первыми.
