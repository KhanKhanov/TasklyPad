# Синтаксис Todoist (для парсеров)

Единственный источник справочника — **docs/TODOIST_SYNTAX.md** (отслеживается git, виден в
репозитории). Прочитай его целиком перед работой над парсером или fixtures; здесь — только порядок работы.

1. Найди в docs/TODOIST_SYNTAX.md раздел по задаче: §1 токены quick add, §2 даты ru/en,
   §3 повторения, §4 язык фильтров, §5 формат fixtures.
2. Форма синтаксиса, которой нет в справочнике или помечена «уточнить по help», — сначала
   проверяется по странице help на todoist.com (агент parity-reviewer), затем дописывается
   в docs/TODOIST_SYNTAX.md и в test/fixtures (qa-tester), и только потом реализуется.
3. Каждый пример из таблиц справочника должен присутствовать в test/fixtures/*.json;
   табличный тест прогоняет все строки файла.
4. Термины UI — как в русской локализации Todoist (.claude/rules/todoist-parity.md).
