# Тестирование

- Обязательные unit-тесты: nlp (даты ru/en, quick add, повторения, фильтры), oplog_sync (HLC, merge,
  транспорты на фейковой ФС), recurrence, karma, filter engine. Парсеры — табличные тесты из
  test/fixtures/*.json с реальными примерами синтаксиса Todoist.
- Widget-тест на каждый экран: smoke + ключевое взаимодействие (добавить, завершить, перетащить).
- integration_test: quick add → Сегодня → завершить → синхронизация двух узлов через temp-папку.
- Детерминизм: фейковые Clock и IdGenerator, `FakeAsync` для таймеров, in-memory drift (`NativeDatabase.memory()`).
- Golden-тесты не используем; визуальная проверка — запуск на Windows + скриншот.
- Имя теста: «что — условие → ожидание». Один смысл на тест.
- Падающий тест → сначала найти причину; менять ожидание под поведение нельзя.
