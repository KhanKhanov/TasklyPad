# Паритет с Todoist

- Эталон — Todoist (web / Windows / Android, 2025–2026). При сомнении — как в Todoist, а не «как лучше».
  Источник: страницы help на todoist.com (агент parity-reviewer их читает).
- Термины UI как в русской локализации Todoist: Входящие, Сегодня, Предстоящие, Фильтры и метки,
  Проект, Раздел, Подзадача, Приоритет 1–4, Срок, Дедлайн, Напоминание, Длительность, Карма.
- Приоритеты: P1 красный (высший), P2 оранжевый, P3 синий, P4 — без цвета (по умолчанию).
- Синтаксис quick add, повторений и фильтров — по скиллу todoist-syntax и docs/TODOIST_PARITY.md;
  каждый пример из fixtures покрыт тестом.
- Хоткеи — как в Todoist desktop; список в docs/TODOIST_PARITY.md §10.
- Вне scope: совместная работа, Google Calendar, AI-функции, интеграции, web-версия (§11).
