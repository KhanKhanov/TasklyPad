# Паритет с Todoist

- Эталон — Todoist (web / Windows / Android, 2025–2026). При сомнении — как в Todoist, а не «как лучше».
  Функционал — 100% как в Todoist (решение пользователя). Источники по убыванию точности: официальные
  скриншоты русского интерфейса Todoist; документация API (developer.todoist.com) — поведение данных;
  страницы help на todoist.com (агент parity-reviewer их читает). Сводка найденного —
  docs/plans/m2-core-app.md «Сверка с Todoist».
- Термины UI как в русской локализации Todoist: Входящие, Сегодня, Предстоящее, Фильтры и метки,
  Мои проекты, Поиск, Добавить задачу, Просмотр (настройки вида), Проект, Раздел, Подзадача,
  Приоритет 1–4, Срок, Дедлайн, Напоминание, Длительность, Карма.
- Приоритеты: P1 красный (высший), P2 оранжевый, P3 синий, P4 — без цвета (по умолчанию); в строке
  задачи — цветная обводка кружка.
- Синтаксис quick add, повторений и фильтров — по скиллу todoist-syntax и docs/TODOIST_PARITY.md;
  каждый пример из fixtures покрыт тестом.
- Хоткеи — как в Todoist desktop; список в docs/TODOIST_PARITY.md §10.
- Вне scope: совместная работа, Google Calendar, AI-функции, интеграции, web-версия (§11).
