# Дорожная карта

Каждый этап завершается полным прогоном проверок синхронизации (`dart test` пакета, `flutter test test/sync`,
двухузловой сценарий через временную папку) и ручной проверкой на обоих устройствах.
Номера пунктов — из docs/TODOIST_PARITY.md.
