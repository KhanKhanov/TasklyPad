# Паритет с Todoist — чек-лист (ТЗ)

Статусы: `[ ]` не начато · `[~]` в работе · `[x]` готово · `[-]` вне scope.
Эталон — Todoist web/Windows/Android 2025–2026 (help на todoist.com). Каждый пункт перед отметкой `[x]` сверяется со страницей help.
Числа «до 4 уровней» и подобные — уточнять по help при реализации, здесь они по памяти.

## 1. Структура данных
- [~] Входящие — проект по умолчанию, нельзя удалить и архивировать (данные: фиксированный id на всех устройствах — M1.4; запрет удаления и архива в UI — M2)
- [ ] Проекты: имя, цвет (палитра Todoist), избранное, архив/восстановление, вложенность (подпроекты, до 3 уровней; подзадачи — до 4), layout на проект (список / доска / календарь), ручной порядок, перетаскивание, дубликат
- [ ] Разделы: имя, порядок, сворачивание, перемещение между проектами, архив, дубликат, удаление вместе с задачами (с подтверждением); до 20 разделов в проекте
- [ ] Задача: название с markdown-подмножеством (жирный, курсив, ссылка, код), описание (markdown), проект + раздел, родитель (подзадачи, до 4 уровней), срок (дата или дата+время с таймзоной), длительность, дедлайн (отдельная дата), приоритет P1–P4, метки, напоминания, комментарии, порядок, завершено + дата завершения, создано, правило повторения
- [ ] Метки: имя, цвет, избранное, порядок, объединение/переименование
- [ ] Фильтры: имя, запрос, цвет, избранное, порядок
- [ ] Комментарии к задачам и проектам: текст (markdown), вложения (файлы и изображения — хранятся в папке синхронизации), дата
- [ ] Журнал активности: добавлено / завершено / обновлено / удалено, фильтр по проекту и дате
- [ ] Завершённые задачи: просмотр по проекту и общий, восстановление, поиск
- [ ] Тост «Отменить» для завершения и переноса; удаление — с подтверждением, без тоста (как в Todoist: «no option to undo task deletion»); длительность тоста в help не указана — 5 с по допущению

- [ ] Автодополнение при вводе `#`, `/`, `@`

## 3. Представления
- [ ] Входящие
- [ ] Сегодня: блок «Просрочено» с «Перенести» (на сегодня / на завтра / выбрать) и «Перенести все», задачи дня по времени, счётчик в сайдбаре
- [ ] Предстоящие: список по дням, недельная полоса календаря сверху, layout календарь (неделя/месяц) с перетаскиванием на дату, блок просроченных
- [ ] Проект: список / доска (колонки = разделы, перетаскивание) / календарь
- [ ] Фильтры и метки: страница со списками; результат фильтра с группами по `,`
- [ ] Поиск: по названию, описанию, комментариям, проектам, меткам, фильтрам; недавние; Ctrl+K командная палитра
- [ ] Избранное в сайдбаре (проекты, метки, фильтры)
- [ ] Панель задачи: боковая на desktop, полноэкранная на телефоне; все поля, подзадачи, комментарии, активность
- [ ] Сортировка (вручную, срок, дедлайн, приоритет, имя, дата добавления) и группировка (нет, проект, раздел, дата, приоритет, метка, дедлайн); показать/скрыть завершённые — сохраняется на каждое представление
- [ ] Множественный выбор (Shift/Ctrl+клик, `x`) и массовые действия: срок, приоритет, проект, метки, завершить, удалить, дубликат
- [ ] Перетаскивание: порядок, в раздел, в проект (сайдбар), индент/аутдент в подзадачу, в календарь, между колонками доски
- [ ] Счётчики задач у проектов и представлений; бейдж количества на сегодня (трей / иконка приложения)

## 4. Фильтры — язык запросов
- [ ] Операторы `&`, `|`, `!`, `( )`, `,` (несколько списков)
- [ ] Даты: today, tomorrow, yesterday, overdue, no date, no time, N days, date/due before/after/on, относительные `+N hours`, `-N days`
- [ ] Дедлайн: deadline, deadline before/after, no deadline
- [ ] Создание: created, created before/after
- [ ] recurring, p1–p4, no priority, `#проект`, `##проект`, `/раздел`, no section, `@метка`, подстановка `*`, no labels, search:, subtask, view all
- [ ] Русские синонимы ключевых слов
- [ ] Подсветка ошибки синтаксиса с позицией; живой предпросмотр результата при редактировании фильтра
- [ ] Сохранённые фильтры: цвет, избранное, порядок, дубликат

## 5. Напоминания и уведомления
- [ ] Абсолютные (дата + время) и относительные (за N мин/ч/дн до срока); несколько на задачу
- [ ] Напоминание по умолчанию для задач со временем (настройка, напр. за 10 мин)
- [ ] У повторяющихся задач напоминания переносятся вместе со сроком
- [ ] Windows: toast с действиями «Завершить», «Отложить 10 мин»; работает из трея
- [ ] Android: уведомление с теми же действиями, точные будильники, после перезагрузки восстанавливаются
- [ ] Ежедневный обзор утром (настройка времени): сколько задач сегодня и просрочено
- [-] Локационные напоминания (Android) — отложено

## 6. Повторяющиеся задачи — семантика
- [ ] Завершение переносит срок на следующее вхождение (от срока; `every!` — от завершения); запись в историю завершений
- [ ] «Пропустить», «Перенести только это вхождение», «Завершить навсегда», редактирование правила, дата окончания
- [ ] Подзадачи повторяющейся задачи снова становятся незавершёнными при новом цикле
- [ ] Отображение правила текстом («каждый пн») и значок повторения

## 7. Карма и продуктивность
- [ ] Карма: очки за завершение (больше за вовремя), за достижение целей; штраф за просрочку старше 4 дней; уровни (Новичок … Просветлённый, пороги уточнить по help); график за неделю/месяц
- [ ] Цели: дневная и недельная, выбор дней недели, серии (streak), режим отпуска
- [ ] Экран «Продуктивность»: завершено сегодня/за неделю, по проектам, тренд
- [ ] Анимация и звук завершения (настраиваются)

## 8. Шаблоны, импорт/экспорт, резервные копии
- [ ] Экспорт/импорт проекта в CSV формата Todoist (TYPE, CONTENT, DESCRIPTION, PRIORITY, INDENT, AUTHOR, RESPONSIBLE, DATE, DATE_LANG, TIMEZONE, DURATION, DURATION_UNIT, DEADLINE …) — совместимость с шаблонами Todoist
- [ ] Шаблоны проектов: сохранить как шаблон, создать из шаблона, встроенные примеры
- [ ] Одноразовый импорт всех данных из аккаунта Todoist (экспорт/API по токену пользователя) — миграция
- [ ] Автоматические резервные копии (ежедневно, хранить N) в папке синхронизации; восстановление из копии
- [ ] Экспорт .ics календаря (только чтение) — опционально

## 9. Настройки
- [ ] Тема: светлая / тёмная / системная + цветовые темы; стартовый экран; язык ru/en; формат даты и времени; начало недели; «следующая неделя» = пн/следующий день
- [ ] Умное распознавание дат вкл/выкл; язык дат; напоминание по умолчанию; звук завершения
- [ ] Уведомления: каналы, тихие часы, ежедневный обзор
- [ ] Синхронизация: папка, статус последней синхронизации, список устройств (узлов), сопряжение по LAN, «пересобрать базу из журнала»
- [ ] Конфликты синхронизации (наше дополнение, в Todoist нет): при параллельной правке одного поля на двух устройствах — уведомление и экран «Конфликты» с обоими вариантами, кнопки «Оставить этот / тот», бейдж; до выбора действует автоматический результат (SYNC_DESIGN «Конфликты»)
- [ ] Резервные копии, экспорт, журнал активности, справка по хоткеям (`?`)
- [ ] Windows: автозапуск, сворачивание в трей при закрытии, глобальный хоткей (Quick Add — `Ctrl+Space`), один экземпляр приложения (повторный запуск показывает открытое окно)
- [ ] Android: виджеты (список «Сегодня», быстрое добавление), ярлыки приложения, share → задача

## 10. Горячие клавиши (desktop) — как в Todoist
Полный список снять со страницы help «Keyboard shortcuts» и держать здесь. Ядро:
- [ ] `q` быстрое добавление · `a` / `Shift+A` добавить задачу внизу/вверху · `S` добавить раздел · `Alt+P` новый проект · `Ctrl+K` командная палитра · `/` или `f` поиск · `?` справка
- [ ] `g` затем `h` Главная, `t` Сегодня, `i` Входящие, `u` Предстоящие, `v` Фильтры и метки, `p` Проекты, `l` Метки
- [ ] В списке: `↑`/`↓` или `j`/`k` фокус, `Enter` открыть задачу, `Ctrl+E` редактировать, `e` завершить, `Shift+Delete` удалить, `1–4` приоритет, `y` сменить приоритет, `t` срок, `Shift+T` убрать срок, `l` метки, `v` перенести, `c` комментарии, `x` выделить, `Shift+E` показать/скрыть подзадачи, `Ctrl+Alt+0` свернуть/развернуть всё, `.` ещё действия, `Esc` закрыть
- [ ] `Ctrl+Z` отменить, `Ctrl+D` дубликат, `m` сайдбар, `Ctrl+↑/↓` перемещение, `Ctrl+]` / `Ctrl+[` индент/аутдент (`Tab` — переход фокуса)
- [ ] В редакторе задачи: `Ctrl+Enter` сохранить, `Esc` отмена, `Ctrl+B/I` жирный/курсив
