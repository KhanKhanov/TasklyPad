# Паритет с Todoist — чек-лист (ТЗ)

Статусы: `[ ]` не начато · `[~]` в работе · `[x]` готово · `[-]` вне scope.
Эталон — Todoist web/Windows/Android 2025–2026 (help на todoist.com). Каждый пункт перед отметкой `[x]` сверяется со страницей help.
Числа «до 4 уровней» и подобные — уточнять по help при реализации, здесь они по памяти.

## 1. Структура данных
- [~] Входящие — проект по умолчанию, нельзя удалить и архивировать (данные: фиксированный id на всех устройствах — M1.4; запрет удаления, архива, переименования и вложения в действиях — M2.1; UI — M2.2)
- [~] Проекты (данные и действия — M2.1; UI — M2.2; доска и календарь — M8): имя, цвет (палитра Todoist), избранное, архив/восстановление, вложенность (подпроекты, до 3 уровней; подзадачи — до 4), layout на проект (список / доска / календарь), ручной порядок, перетаскивание, дубликат
- [~] Разделы (данные и действия — M2.1; UI — M2.2): имя, порядок, сворачивание, перемещение между проектами, архив, дубликат, удаление вместе с задачами (с подтверждением); до 20 разделов в проекте
- [~] Задача (поля, подзадачи, срок, дедлайн, длительность, приоритет, метки, порядок, завершение — M2.1; markdown, напоминания, комментарии, повторения — позже): название с markdown-подмножеством (жирный, курсив, ссылка, код), описание (markdown), проект + раздел, родитель (подзадачи, до 4 уровней), срок (дата или дата+время с таймзоной), длительность, дедлайн (отдельная дата), приоритет P1–P4, метки, напоминания, комментарии, порядок, завершено + дата завершения, создано, правило повторения
- [~] Метки (данные и действия — M2.1; страница «Фильтры и метки», экран метки, диалог, меню — M2.2; объединение в help не найдено): имя (до 60 символов), цвет, избранное, порядок, переименование; до 500 меток и до 100 на задачу (help «Usage limits», О-27); удаление снимает метку с активных задач, на выполненных она остаётся (О-26)
- [ ] Фильтры: имя, запрос, цвет, избранное, порядок
- [ ] Комментарии к задачам и проектам: текст (markdown), вложения (файлы и изображения — хранятся в папке синхронизации), дата
- [ ] Журнал активности: добавлено / завершено / обновлено / удалено, фильтр по проекту и дате
- [ ] Завершённые задачи: просмотр по проекту и общий, восстановление, поиск
- [~] (M2.2: завершение, перенос и смена срока — с тостом; удаление — с подтверждением) Тост «Отменить» для завершения и переноса; удаление — с подтверждением, без тоста (как в Todoist: «no option to undo task deletion»); длительность тоста в help не указана — 5 с по допущению

## 4. Фильтры — язык запросов
- [ ] Операторы `&`, `|`, `!`, `( )`, `,` (несколько списков)
- [ ] Даты: today, tomorrow, yesterday, overdue, no date, no time, N days, date/due before/after/on, относительные `+N hours`, `-N days`
- [ ] Дедлайн: deadline, deadline before/after, no deadline
- [ ] Создание: created, created before/after
- [ ] recurring, p1–p4, no priority, `#проект`, `##проект`, `/раздел`, no section, `@метка`, подстановка `*`, no labels, search:, subtask, view all
- [ ] Русские синонимы ключевых слов
- [ ] Подсветка ошибки синтаксиса с позицией; живой предпросмотр результата при редактировании фильтра
- [ ] Сохранённые фильтры: цвет, избранное, порядок, дубликат

## 5. Напоминания и уведомления
- [ ] Абсолютные (дата + время) и относительные (за N мин/ч/дн до срока); несколько на задачу
- [ ] Напоминание по умолчанию для задач со временем (настройка, напр. за 10 мин)
- [ ] У повторяющихся задач напоминания переносятся вместе со сроком
- [ ] Windows: toast с действиями «Завершить», «Отложить 10 мин»; работает из трея
- [ ] Android: уведомление с теми же действиями, точные будильники, после перезагрузки восстанавливаются
- [ ] Ежедневный обзор утром (настройка времени): сколько задач сегодня и просрочено
- [-] Локационные напоминания (Android) — отложено

## 6. Повторяющиеся задачи — семантика
- [ ] Завершение переносит срок на следующее вхождение (от срока; `every!` — от завершения); запись в историю завершений
- [ ] «Пропустить», «Перенести только это вхождение», «Завершить навсегда», редактирование правила, дата окончания
- [ ] Подзадачи повторяющейся задачи снова становятся незавершёнными при новом цикле
- [ ] Отображение правила текстом («каждый пн») и значок повторения

## 7. Карма и продуктивность

## 10. Горячие клавиши (desktop) — как в Todoist
Источник — help «Use keyboard shortcuts» (сверено 26.10.2026); «`g` `i`» — клавиши по очереди.
- [~] Общие (M2.2: `m`): `q` быстрое добавление · `Alt+P` новый проект · `/` или `f` поиск · `Esc` отмена · `Ctrl+Z` отменить · `m` сайдбар · `?` справка · `Ctrl+K` командное меню · `Ctrl+Alt+0` свернуть/развернуть всё · `Ctrl+1/2/3` Входящие/Сегодня/Предстоящее · `Ctrl+4/5` Проекты/Фильтры и метки · `Ctrl+Shift+P/L/F` новый проект/метка/фильтр · `Ctrl+F` поиск · `Ctrl+,` настройки · `Ctrl+S` синхронизация; глобально — `Ctrl+Space` быстрое добавление, `Win+Alt+S` показать/скрыть
- [~] Переходы (M2.2: `g i`, `g p`, `g v`, `g l`): `h` или `g h` Главная · `g i` Входящие · `g t` Сегодня · `g u` Предстоящее · `g l` Метки · `g p` Проекты · `g /` раздел · `g v` Фильтры и метки · `g a` отчёты · `o p` Продуктивность · `o s` Настройки · `o t` Тема · `Shift+G` открыть задачу в её проекте · `Alt+←/→` назад/вперёд
- [~] Задача в фокусе (M2.2: `↑`/`↓`, `j`/`k`, `Enter`, `e`, `t`, `Shift+T`, `1–4`, `y`, `l`, `v`, `Shift+Delete` — у нас удаляет задачу в фокусе, выделение — M4): `j`/`k` или `↑`/`↓` фокус · `Enter` открыть · `Ctrl+E` редактировать · `e` завершить · `t` / `Shift+T` срок / убрать срок · `1–4` приоритет, `y` сменить · `c` комментарий · `l` метки · `v` перенести · `.` ещё действия · `x` выделить · `Ctrl+клик` / `Shift+клик` выделить несколько · `,` панель выделения · `Shift+Delete` удалить выделенное · `Ctrl+Shift+C` ссылка на задачу
- [~] Подзадачи, создание, проект (M2.2: `Ctrl+]` / `Ctrl+[`, `Shift+E`, `a` / `Shift+A`, `S`): `Ctrl+]` / `Ctrl+[` в подзадачу / из подзадачи · `Shift+E` показать/скрыть подзадачи · `a` / `Shift+A` добавить внизу / вверху · `S` раздел · `Shift+V` вид проекта · `w` действия проекта · `d` / `p` / `n` / `r` сортировка · `Ctrl+Home` / `Ctrl+End` в начало / конец
- [~] Панель задачи (M2.2: `J` / `K` и стрелки в заголовке, `Esc`): стрелки в заголовке, `J` / `K` следующая / предыдущая задача списка (клавиши в help не описаны — О-24) · `Esc` закрыть · `Ctrl+Enter` сохранить правку (в добавлении задачи — сохранить и создать выше) · `Ctrl+↑/↓` — к задаче выше / ниже при редактировании (это не перемещение задачи) · `Tab` — фокус по элементам панели
- [ ] В редакторе задачи: `Enter` сохранить и новая ниже · `Shift+Enter` сохранить правку и новая ниже · `Ctrl+B/I` жирный/курсив (по памяти — проверить)
