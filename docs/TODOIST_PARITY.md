# Паритет с Todoist — чек-лист (ТЗ)

Статусы: `[ ]` не начато · `[~]` в работе · `[x]` готово · `[-]` вне scope.
Эталон — Todoist web/Windows/Android 2025–2026 (help на todoist.com). Каждый пункт перед отметкой `[x]` сверяется со страницей help.
Числа «до 4 уровней» и подобные — уточнять по help при реализации, здесь они по памяти.
