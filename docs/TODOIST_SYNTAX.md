# Синтаксис Todoist — справочник для парсеров

Справочник собран по help на todoist.com. §1–§3 сверены 31.10.2026 со страницами «Use Task Quick Add»,
«Introduction to dates and time» (en, ru), «Introduction to recurring dates» (en, ru), «Set a task
duration» (en, ru); §4 — по памяти, сверка — при реализации фильтров (M5). Форма, которой в help нет,
помечена «допущение»: она остаётся в разборе до сверки на живом Todoist (О-57, решение 7А плана M3).
Новая форма сначала дописывается сюда и в test/fixtures, потом реализуется. Чек-лист функций —
docs/TODOIST_PARITY.md (§2, §4, §6). Разбор — lib/nlp.

Общие правила разбора:
- язык разбора — язык интерфейса, один за раз (help «Change languages»); язык пишется в срок (`lang`);
- распознанное подсвечивается и убирается из названия; клик по подсветке оставляет текст в названии
  (help «Use Task Quick Add»), Backspace сразу после даты — тоже (help «Turn smart date recognition on
  or off»; Delete перед датой и клик по прочим токенам — допущение);
- выключенное «Умное распознавание даты» отключает разбор даты, отрезка времени и дедлайна `{…}` в
  названии — их ставит только планировщик (help); остальные токены §1 разбираются (допущение);
- дата — до 150 символов (help); в названии берётся первая дата, следующие остаются текстом (допущение);
- токены `#`, `/`, `%`, `@` начинаются в начале слова: `a@b.ru` и `и/или` — текст (допущение);
- дата не перешагивает разобранный токен: в «Call tomorrow #Work at 5pm» срок — `tomorrow`; фраза
  `every`, которая не разобралась (`every 27th and 3rd fri`), остаётся текстом целиком (допущение);
- регистр, «ё» и «е» не различаются.

## 1. Quick Add — токены

| Токен | Пример | Смысл и источник |
|---|---|---|
| `#Проект` | `#Работа` | проект, существующий или новый (help); имя с пробелами — `#"Дом и быт"` (допущение) |
| `/Раздел` | `#Работа /Встречи` | раздел проекта; в help — после проекта, без проекта — раздел текущего (допущение) |
| `%метка` | `%email %дом` | метки, несколько подряд (help); `@метка` работает до конца 2026 (help) |
| `p1`…`p3` | `p1` | приоритет (help); `p4` — без приоритета, тоже распознаётся (допущение); берётся первый |
| `!` + время | `!14:00`, `!30 min before` | напоминание (help); до M7 остаётся в названии и не разбирается как срок |
| `{дата}` | `{march 30}`, `{28 фев}` | дедлайн — дата без времени (help «Introduction to dates and time») |
| `for` / `в течение` | `for 1h`, `for 10m`, `for 1h15m`; `в течение 2ч`, `в течение 10мин`, `в течение 1ч15мин` | длительность (help «Set a task duration»): `h`/`ч` — часы, `m`/`мин` — минуты; до 24 ч; можно без срока |
| отрезок времени | `from 21:00 to 22:00`, `9:30-10:00`; `с 21:00 до 22:00` | время срока и длительность (help; русская форма — допущение) |
| `//` | `Купить молоко //2 литра` | всё после — описание (допущение; в help описание открывают «+» или `↓`) |
| дата в тексте | `tomorrow at 4 pm`, `завтра в 16:00` | срок по §2 и §3 |
| несколько строк | вставка текста с переносами | «Добавить X задач?» (help «Add or manage multiple tasks», M3.6) |

Длительность больше 24 ч остаётся в названии (допущение).

## 2. Даты

Значения — от «сейчас»; дата без года и день недели — ближайшие будущие. «Сегодня не считается» и
«время прошло — завтра» отмечены там, где это сказано в help; остальное — допущения.

|---|---|---|
| `today`, `tod` | `сегодня` | сегодня |
| `tomorrow`, `tom` | `завтра` | завтра |
| — | `послезавтра` | через 2 дня (допущение) |
| `yesterday` | `вчера` | вчера (допущение) |

Дни недели — полные и короткие: `monday`…`sunday`, `mon`, `tue`, `tues`, `wed`, `thu`, `thur`, `thurs`,

`вс`, `сред`. Месяцы — полные и первые три буквы (`sep`, `sept`; `сент`), по-русски во всех падежах.

| `noon` | `полдень` | 12:00 |
| `in the morning` | `утром` | 9:00 |
| `in the afternoon` | `днём` | 12:00 |
| `in the evening` | `вечером` | 19:00 |
| — | `ночью` | 22:00 |

в любом порядке.

## 3. Повторения

Правило хранится строками RRULE и флагом `from_completion` (SYNC_DESIGN «Проекции»); первое вхождение —
сегодня или с даты `starting`, только будущее. Новая форма, которой формат правила или расчёт
`nextOccurrence` не выражает, — Decision Gate.

| en | ru | RRULE и смысл |
|---|---|---|
| `every day`, `daily`, `everyday` | `каждый день`, `ежедневно` | `FREQ=DAILY` |
| `every weekday`, `every workday` | `каждый рабочий день`, `каждый будний день` (допущение) | `FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR` |
| `every week`, `weekly` | `каждую неделю`, `еженедельно` | `FREQ=WEEKLY` — день недели срока |
| `every month`, `monthly` | `каждый месяц`, `ежемесячно`, `ежемесячный` | `FREQ=MONTHLY` — число срока, 29–31 прижимаются к концу короткого месяца |
| `every year`, `yearly` | `каждый год`, `ежегодно` | `FREQ=YEARLY` |
| `every quarter`, `quarterly` | `каждый квартал`, `ежеквартально` | `FREQ=MONTHLY;INTERVAL=3` |
| `every hour` | `каждый час` | `FREQ=HOURLY`, с текущего момента |
| `every 12 hours starting at 9pm` | `каждые 12 часов с 9:00` | `FREQ=HOURLY;INTERVAL=12`, первое — в указанное время |
| `every 3 days`, `every 6 weeks`, `every 3 months` | `каждые 3 дня`, `каждые 6 недель`, `каждые 3 месяца` | `INTERVAL=N` |
| `every other day/week/month/year` | `каждые два дня`, `каждую вторую неделю`, `каждый второй месяц`, `каждый второй год` | `INTERVAL=2` |
| `every mon, fri`, `every monday, friday`, `every mon, tues, wed, and fri` | `каждый пн, пт`, `каждый понедельник, пятницу` | `FREQ=WEEKLY;BYDAY=MO,FR` |
| `every other fri` | `каждую вторую пт` | `FREQ=WEEKLY;INTERVAL=2;BYDAY=FR`, со второй пятницы; с `starting` — с первой после даты (допущение) |
| — | `каждые выходные` | `FREQ=WEEKLY;BYDAY=SA` — по субботам |
| `every 27th`, `every 2, 15, 27` | `каждое 27-е`, `каждое 27`, `каждое 2, 15, 27` | `FREQ=MONTHLY;BYMONTHDAY=27` / `=2,15,27` |
| `every last day` | `каждый последний день` | `FREQ=MONTHLY;BYMONTHDAY=-1` |
| `every 3rd friday`; `every last friday` (допущение) | `каждую 3 пятницу`; `каждую последнюю пт` (допущение) | `FREQ=MONTHLY;BYDAY=3FR` / `-1FR` |
| `every first workday`, `every 15th workday`, `every last workday`, `every 7th workday` | `каждый первый рабочий день`, `каждый 15 рабочий день`, `каждый последний рабочий день`, `каждый 3 рабочий день`, `каждый 7-й рабочий день` | `FREQ=MONTHLY;BYDAY=MO,TU,WE,TH,FR;BYSETPOS=1` / `15` / `-1`: n-й рабочий день месяца |
| `every 3 workday` | `каждые 3 рабочих дня` (допущение) | каждые N рабочих дней — не поддерживается (О-63), остаётся текстом |
| `every jan 27`, `every July 19` | `каждое 27 янв` | `FREQ=YEARLY;BYMONTH=1;BYMONTHDAY=27` |
| `every 14 jan, 14 apr, 15 jun, 15 sep` | `кажд 14 янв, 14 апр, 15 июн, 15 сент` | по строке на дату: `FREQ=YEARLY;BYMONTH=1;BYMONTHDAY=14`, … |
| `every 1st wed jan, 3rd thu jul` | `каждую 1 среду янв, 3 чт июл` | `FREQ=YEARLY;BYMONTH=1;BYDAY=1WE` и `FREQ=YEARLY;BYMONTH=7;BYDAY=3TH` |
| `every 15th workday, first workday, last workday` | `каждый 15 рабочий день, первый рабочий день, последний рабочий день` | `…;BYSETPOS=15,1,-1` |
| `every valentine`, `every halloween` (допущение) | `каждый хэллоуин` (допущение) | ежегодно в праздник |
| `every morning`, `every afternoon`, `every evening`, `every night` (допущение) | `каждое утро`, `каждый полдень`, `каждый вечер`, `каждую ночь` | `FREQ=DAILY` в 9:00, 12:00, 19:00, 22:00 |
| `every mon, fri at 20:00`, `every fri at noon`, `every last workday at 3pm`, `every 2 days at 12:00` | `каждый пн, пт в 20:00`, `каждую 3 пятницу в 8`, `каждую пт днём`, `каждый пн утром`, `кажд сред вечером` | время — в срок, не в правило |
| `every! 3 hours`, `every! 2 months` | `каждые! 3 часа`, `каждые! 5 дней`, `каждые! 2 месяца`, `каждый!` (допущение) | `from_completion: true` — от выполнения |
| `after 10 days` | `через 10 дней начиная с 10 авг` | `every! 10 days`; просто `через 10 дней` — однократная дата (§2, решение 7А) |
| `everyday starting on aug 3`, `everyday from aug 3`, `every 14 days 7am starting 1 Nov` | `каждый день начиная с 3 августа`, `каждый день с 3 августа`, `каждые 6 недель в 9:00 начиная с 3 янв` | первое вхождение — не раньше даты |
| `everyday ending aug 3`, `everyday until aug 3` | `каждый день до 3 августа` | `UNTIL=20270803` — дата, конец дня включительно |
| `every Wednesday, Friday, Saturday ending Saturday` | `каждую среду, пятницу, субботу заканчивая в субботу` | `UNTIL` — ближайшая суббота |
| `everyday for 3 weeks` | `каждый день в течение 3 недель` | `UNTIL` — последний день трёх недель от начала |
| `everyday from 10 May until 20 May` | `каждый день с 10 мая до 20 мая` | начало и `UNTIL` |
| `every 3rd Tuesday starting Aug 29 ending in 6 months` | `каждый 3 вторник начиная с 20 августа заканчивая через 6 месяцев` | `UNTIL` — через 6 месяцев от начала (допущение) |

`ev` и `кажд` — сокращения `every` и «каждый». Не поддерживается (help): разное время для разных дней
(`every mon at 8pm, tue at 9pm`), `except` / «кроме», два `every` в одной фразе, «каждые N месяцев в
первую пятницу». `N раз` / `for 5 times` в help нет, а `COUNT` формат правила не допускает — не
распознаётся.

Семантика выполнения, «Отложить», переноса вхождения и подзадач — plans/m3 «Сверка с Todoist» и
решения 6, 10; расчёт — lib/domain/recurrence.dart. Все переходы — через ops (docs/SYNC_DESIGN.md).

## 4. Язык фильтров

Операторы: `&` и, `|` или, `!` не, `( )` группировка, `,` — несколько списков в одном фильтре
(каждый список — отдельная секция результата).

| Запрос | Смысл |
|---|---|
| `today`, `tomorrow`, `yesterday` | срок в этот день |
| `overdue`, `od` | просрочено |
| `no date`, `no due date` | без срока; `no time` — срок без времени |
| `7 days`, `next 7 days`, `next week`, `this week` | диапазоны |
| `date before: May 5`, `date after: today`, `due before: +4 hours`, `date: Jan 3` | сравнение; `due` и `date` эквивалентны; относительные `+N hours/days`, `-N days` |
| `deadline: today`, `deadline before:`, `deadline after:`, `no deadline` | по дедлайну |
| `created: today`, `created before: -30 days`, `created after:` | по дате создания |
| `recurring`, `!recurring` | повторяющиеся |
| `p1`, `p2`, `p3`, `p4`, `no priority` (= p4) | приоритет |
| `#Работа`, `#"Два слова"`, `##Работа` | проект; `##` — включая подпроекты |
| `/Встречи`, `no section` | раздел |
| `@дом`, `@дом*`, `no labels`, `@*`? | метки; `*` — подстановка (уточнить по help) |
| `search: отчёт` | текст в названии/описании |
| `subtask`, `!subtask` | подзадачи |
| `view all` | все активные задачи |
| `assigned to:`, `assigned by:`, `shared`, `workspace:` | **вне scope** — распознать и показать «не поддерживается» |

Ключевые слова — английские; русские эквиваленты (`сегодня`, `просрочено`, `без даты`, `без меток`)
поддержать как синонимы. Имена проектов/меток — без учёта регистра. Ошибка синтаксиса — подсветка
позиции и сообщение, как в Todoist; пустой результат — не ошибка.
