## Риски
- Сборка M3 не знает новых молчащих полей и типа — покажет лишние карточки и не скопирует описание при
  дубликате: профили обновлять вместе.
- Своё перетаскивание — самый объёмный шаг; файлы виджетов — в пределах 300 строк.
- Сортировка и группировка на каждом снимке `Workspace` — замер вместе с О-52 (M6).
- Markdown рядом с токенами быстрого добавления (`#`, `*`, `_`) — тесты разбора в M4.12.
- Help по видам краток, список О-69 большой — пункты PARITY могут остаться `[~]` до скриншотов.
