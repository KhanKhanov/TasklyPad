# features

Фичи по папкам: <feature>/{ui,state,logic}. tasks, projects, sections, labels, filters, quick_add, views (inbox/today/upcoming), reminders, search, karma, templates, import_export, settings.

`common/ui` — общее для экранов: `ui_kit.dart` (виджеты), `layout.dart` (ширины раскладки), `device_title.dart` (название устройства в списках).
